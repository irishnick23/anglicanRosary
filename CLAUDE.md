The Daily Office is a static HTML, CSS, and JavaScript prayer guide. Open index.html locally or serve the repository root. The app loads bundled services from assets/offices first. Run python3 scripts/bundle-offices.py to refresh the local date range. Other dates use the Daily Office 2019 API with its KJV scripture setting. The response supplies liturgical modules and lines. The app stores previously loaded services by office and date for reuse if the API is unavailable. app.js also renders the animated sand cloud.
